# Contributing

Keep changes focused and include the context needed to reproduce an issue. Do not commit datasets, private credentials, generated experiment outputs, or model checkpoints.

For bug reports, include the commit, Python and framework versions, operating system, hardware, command, and full error. For fixes, add a small regression test and run the maintenance checks described in the README.

Changes to sampling, randomness, losses, aggregation, or training schedules must explain their effect on the research baseline and include appropriate experimental validation. Keep maintenance checks distinct from evidence that paper results have been reproduced.

Retain existing attribution and licenses. See [PROVENANCE.md](PROVENANCE.md) for the source snapshot.
