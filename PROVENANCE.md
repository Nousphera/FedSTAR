# Source credits

FedSTAR is based on [FederatedML/FedSTAR](https://github.com/FederatedML/FedSTAR),
by Vasileios Tsouvalas, Aaqib Saeed and Tanir Ozcelebi. Source commit
[`a457290fcd172d5fe8c978e49b2d1bd7df91987c`](https://github.com/FederatedML/FedSTAR/commit/a457290fcd172d5fe8c978e49b2d1bd7df91987c)
is available under the `federatedml-baseline` tag. Author attribution and Git
history are retained.

The `fedstar/` package provides TensorFlow/Keras training and native Flower
ClientApp/ServerApp entry points. The repository also includes the upstream
`src/` files and dataset split lists. Use the [root installation instructions](README.md)
for the current package and the [method guide](docs/METHOD.md) for its settings.

external-model terms remain with their respective providers.
